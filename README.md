### `01 // EMERGENCY RESPONSE` — GeoCESAR

Plataforma en desarrollo para emergencias rurales. Busca conectar solicitudes de ayuda con equipos de respuesta, compartir la ubicación de las personas y facilitar el seguimiento de cada incidente.

**Stack:** Java · Spring Boot · React · React Native · MIOTY · PostGIS

### `02 // ENTERPRISE B2B` — CEQ Marketplace

Marketplace B2B del Clúster Energético de Querétaro. Lideré un equipo de cuatro personas y desarrollé módulos full stack para una plataforma desplegada en VPS. La landing es pública; las funciones requieren autenticación.

**Stack:** NestJS · React · PostgreSQL · Redis · VPS

### `03 // IoT TELEMETRY` — IMOX Cloud

Backend de telemetría MQTT para calidad eléctrica, desplegado con Docker en un servidor físico de recursos limitados. Atendió más de 50 dispositivos concurrentes con intervalos de 1.5 segundos; la validación de timestamps ayudó a evitar falsas desconexiones. También implementé OTA y caché Redis.

**Stack:** NestJS · MQTT · Redis · Docker · OTA

### `04 // GYM MANAGEMENT` — Fitness Gym

Sistema de membresías, acceso con QR, inventario y reportes para un gimnasio de más de 150 miembros.

**Stack:** Angular · NestJS · PostgreSQL · Serverless

### `05 // SOFTWARE & DIGITAL SERVICES` — Linkore Solutions

Iniciativa personal para desarrollar soluciones de software, IoT y marketing digital para clientes.

**Stack:** Next.js · Tailwind · Framer Motion · Meta Ads

### `06 // RURAL HEALTH` — VozRural

Proyecto de hackathon enfocado en telemedicina para comunidades rurales mediante interacción por voz y WhatsApp. Incluyó una prueba de concepto de wearable con GPS.

**Stack:** Node.js · ESP32 · WhatsApp

### `07 // AGRICULTURAL AI` — Lettucecurity

Prototipo de monitoreo agrícola que exploró la detección visual de plagas y la predicción de variables ambientales con modelos de aprendizaje automático.

**Stack:** NestJS · TensorFlow · React · MQTT
